## B. 미해결 — 최우선

### B-1. `animate` 템플릿 버그 🔴
**증상**: 코드 주석은 *"시작 이미지에 이미 HUD가 있으면 그걸 살린다"* 인데, 실제 문구는 *"Open the clip with that overlay **not yet there**, and draw it on"* — **지웠다 다시 그리게** 한다.

**실측 확인** (트로이 편 실제 프롬프트):
```
'HUD 지웠다 다시 그려라' 포함 컷: 2개 (#3, #9)
그 중 '글자 그대로 유지'와 동시 포함: 2개  ← 100% 충돌
```
컷 9에는 *"치수선을 지웠다 다시 그려라"* 와 *"치수선에 얹힌 x30은 절대 지우지 마라"* 가 **한 프롬프트에 같이** 들어갔다.

**문제 3가지**
1. `arrow_animate`·`zone_animate`·`glow_animate`·`reject_animate`·`manga_animate`·`flow_animate` **전부** "이미 있고 빛만 지나간다"인데 기본 `animate`만 반대 — 패밀리 불일치
2. 2K에 구운 헤어라인을 720p에서 재작도 = 우리가 문서화한 대표 실패 모드
3. 체인의 "HUD 중복 방지" 분기가 무력 (animate도 다시 그리므로). 게다가 그 시작 프레임은 이미 720p 렌더라 **재작도의 재작도**

**영향 범위**: `img_anno` 기본값이 `auto`라 주석 켜진 컷은 이미지에 주석이 구워지고 → `_video_anno_kind`가 대부분 `animate`를 고른다. 주석 컷의 다수가 이 경로.

**수정안**: 다른 `*_animate`와 같은 문법으로 — HUD는 이미 있고 고정, 헤어라인을 따라 **밝은 빛이 한 번 지나가며** 눈금이 차례로 켜짐, 이후 은은한 발광 유지. 채널 시그니처인 "그려지는 느낌"은 지나가는 빛으로 살린다.
**주의**: 마지막 문장 `"no letters, digits or words."`는 `main.py:5511`이 치환하는 대상이라 **글자 단위로 유지**해야 함.

### B-2. 이미지 편집 모드 부재 🟡
레퍼런스 채널(신비한 건축사전)이 AI만으로 그 일관성을 내는 방법을 프레임에서 확인했다: **베이스 이미지 1장을 편집으로 파생**시킨다.
- `TOTAL MASS` → `COUNTED MASS`: 피라미드 픽셀 동일, 라벨만 다름
- `LOAD DISTRIBUTION` → `LATERAL BYPASS`: 같은 박공, 하중선만 더 자람
- `1765`가 4프레임에 걸쳐 커짐: 같은 방, 숫자 크기만 변함

우리 참조 이미지 모드는 두 개뿐:
- `STYLE_REF_LINE` — "톤만 따라하고 **피사체·구도는 복사하지 마라**"
- `CHAR_SHEET_LINE` — "이 인물만 그대로"

**"이 이미지를 그대로 두고 주석만 얹어라"가 없다.** 이게 생기면 상태 변화쌍·단계적 성장 연출이 열리고, 무엇보다 **컷 간 피사체 일관성이 캐논 문구보다 근본적으로 해결**된다. `_gen_image`가 이미 참조 이미지를 인라인 전송하므로 프롬프트 문구 + 배선만 추가하면 된다.
