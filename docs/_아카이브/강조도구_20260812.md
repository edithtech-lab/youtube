## 1. 왜 손댔나 — 실측 근거

### 슬롯이 하나뿐이라 축을 못 정했다

`focus_en` 한 칸으로 다섯 도구를 감당하다 보니, 두 점을 잇는 도구가 어긋났다.

```
"천장이 43m 위에 있는데"  →  focus_en: "the corbelled ceiling high above"
결과 3회                    천장 경사면 / 통로 가로폭 / 천장 근처 아무 축
```

`from_en`·`to_en` 을 주자 3회 모두 바닥→천장 수직 치수선이 나왔다.
`arrow` 는 더 심했다 — 하중이 좌우로 갈라지는 핵심을 못 그려 **설명이 뒤집혔다**
(방들이 하중을 흘려보내는 구조인데, 하중이 방을 뚫고 내려가는 것처럼 보였다).

### hud 라는 이름이 프롬프트를 SF 쪽으로 밀었다

```
"A holographic technical HUD in cyan switches on over the scene..."
```

같은 골격에서 첫 문장만 `"A technical dimension line is drawn..."` 으로 바꾸자
엉뚱한 축에 붙던 수치가 바로잡혔다. 이름보다 **문구가 원인**이었다.

### 바닥 원형 그리드가 조건 없이 깔렸다

조건이 `shot == "wide"` 하나뿐이라 실내·단면 와이드에도 바닥 원판이 생겼다.
야외 측량 컷에만 어울리는 장치인데 `shot` 만으로는 가려낼 수 없어 **걷어냈다**.

### 질감 지정이 아예 없었다

`arrow` `reject` 는 *"clean solid"* 뿐이라 평평한 2D 스티커처럼 붙었다.
질감 4종을 뽑아 비교한 결과 **유리·리본**이 선택됐다(네온 튜브는 가늘어서 방향이 약하고,
무광 인쇄는 존재감이 없었다).
