# 레퍼런스 4편 분석 (2026-08-19)

> 대상: 군함 천 가림 / 다락 비행기 / 성벽 자가감금 / 스텔스 톱니 (각 360×640·30fps·1분44초~2분09초)
> 방법: 10fps 전 프레임 기계 측정(밝기·채도·R−B·색상 점유·컷 검출) + 24프레임 격자 시각 판독.
> 타 AI 분석을 교차 검증함 — 아래 ✅/⚠ 표기.

| 다락 비행기 | 100 | 65 | +21.2 | 7.3% / 58% | 0.6% | 3.7s |

- **강조색은 빨강이 맞다** (전편) — 우리 시안·파랑과 정반대. 시안 계열 그래픽은 사실상 없음
  (군함천의 cyan 6.5% 는 수중 물색이 잡힌 것).
- 타 AI 의 밝기·R−B·채도는 **거의 정확** ✅. 컷 중앙값은 성벽·스텔스에서 검출법 차이로
  1.5~2초 어긋남 ⚠ (양쪽 다 자동 검출 — 3.5~6초 범위라는 결론은 동일).
- 타 AI 의 "권장 hex 팔레트"는 측정이 아니라 발명값 ⚠ — 참고만.
- **근흑 ≈ 0~1.4%**: 이 채널들은 검은 무대를 안 쓴다 (우리 기존 레퍼런스 실측 17%와 대조).
  흰 무대도 순백이 아니라 회색·베이지 (근백 0.1% 미만) ✅.

## 2. 시각 판독 — 도구 매핑 (우리 25종 대비)

레퍼런스에서 본 것 중 **우리에게 이미 있는 것**: wave(소나 동심원), measure(15.2m·46km·
BLOCK12 도면), outline, zone(붉은 면), flow, route(지도 화살표), trajectory, spin(회전 링),
glow(덕트 내부 발광), gauge(70% 원), graph(붉은 막대), count(80,000), crack, marker,
label, reject(대형 X — No Answer / True Target).

**우리에 없는 것 (신규 후보 3)**:
1. **ghost(잔상)** — 이전 상태·다른 위치를 반투명으로 겹침 (False Ghost 등). skeleton·void 와 다름.
2. **seamglow(이음새 발광 추적)** — 톱니 이음새를 따라가는 발광선. crack(파손)과 의미가 다름
   — 파손이 아니라 **정상 구조의 경계**.
3. **추상 문제 무대** — 성벽편 46~56초: 실제 장면을 버리고 회색 그리드 + 파랑/빨강 블록으로
   문제를 재구성 (모래시계 압착 → X 파쇄 → 블록 군대). 도구가 아니라 **style 후보**.

타 AI 후보 8종 중 FIELD_WAVE=wave, MEASURED_VOLUME=bracket/measure, LOUD_NEGATION=reject,
FORCE_CROWD_FLOW≈flow+loadsplit 로 **이미 커버** ✅. MATERIAL_APPLICATION(테이프·천 부착)은
도구가 아니라 모션 유형 — motion_en 으로 이미 가능.

## 3. 리듬·문법에서 얻은 것

- **큰 영어 결론 단어** (The Screw / No Answer / Sickle Curve / Zigzag / By Hand / Flip It):
  문단이 끝날 때 화면 중앙 대형 타이포. 4편 전부에서 반복되는 핵심 후킹 장치.
- **강조 펄스 구조**: 평시 0~1% → 강조 5~12% → X·전면 원 순간 20~80%. 고정 점유율이 아니라
  시간 평균 ~3%다 ✅ (우리 3.1% 실측과 일치).
- 전환은 하드컷 + 같은 형태·축 매치컷. 화려한 트랜지션 0 ✅.
- CAMERA_LOUD 역상관 (그래픽 클수록 카메라 정지) ✅ — **우리가 이미 구현한 규칙과 동일**.
- 치수(measure)만 양방향 화살표, 방향(arrow)은 단방향 — 우리 #7 실측(양방향 오염)과 연결.

## 4. 팔레트 결론 (사용자 목적)

레퍼런스는 두 계열로 갈린다:
- **TECH_COOL** (군함·스텔스): 청회색, R−B −7, 채도 38~67, 금속. 스텔스편은 채도 38로 매우 낮음.
- **HISTORY_WARM** (비행기·성벽): 미색·카키·목재·붉은 지붕, R−B +13~+21, 밝기 100~116.

강조색: 레퍼런스는 전부 **빨강** — 배경(청회·카키)과 보색이라 분리가 강함.
우리는 시안 — 물·하늘 컷에서 묻힐 수 있는 구조적 약점이 있음 (군함천 수중 컷 참조).
→ 톤 신설 시 강조색을 같이 정할 것 (전환/유지/톤별은 사용자 결정 사항).
