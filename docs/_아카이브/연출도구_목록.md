# 우리 시스템에서 실제로 쓸 수 있는 연출·VFX 도구 전체 목록

기준일 2026-08-12. **"코드에 배선되어 실제 생성에 쓰이는 것"만 담았다.**
각 항목의 근거는 `main.py` 줄 번호. 앱을 고칠 때 이 표가 최신인지 같이 확인할 것.

## 1. 구조를 드러내는 방식 (CAD 계열의 핵심)

GPT 마스터 프롬프트 §7이 말한 5가지 리빌 방식과 우리 도구의 대응.

| 리빌 방식 | 우리 도구 | 사용법 | 근거 |
|---|---|---|---|
| **Cutaway** (일부 제거) | `shot: cutaway` | 어떤 톤에도 붙는 샷 지정. "속·단면·내부를 실제로 가르는 컷에만" | `SHOT_LINES` L1998 |
| **Section View** (절단면) | `style: xsection` | 톤 자체가 "잘라서 속을 보여주는 실물 시연" | `STYLE_DEFAULTS["xsection"]` L1533 |
| **X-Ray** (투시) | **홀로그램 ② 투시 재구성** | 실물 벽은 불투명 유지 + 위에 시안 와이어프레임 투영 | 분해규칙 [3-1]② L2176 |
| **Breakout** (부분 공개) | `anno_kind: zone` + cutaway | 영역 테두리로 한 구획만 짚기 | `ANNOTATION_ZONE` L1634 |
| **Exploded View** (분해) | **`subject_en` 에 "compact exploded view"** | 2026-08-12 추가. 건축·유적 내부 구획에도 사용 | [5-2] · `is_exploded_cut()` L1135 |

> **X-Ray 는 GPT안보다 우리가 한 단계 위다.** GPT는 "외피 투명도를 낮춰라"인데,
> 우리는 실물을 불투명하게 두고 그 위에 투영을 겹친다 — 영상 모델이 껍질을 투명하게
> 만들려다 물체를 녹여버리는 실패를 아예 피한다 (홀로그램 규칙, L2176).

## 2. 강조 도구 (컷당 반드시 하나)

`anno_kind` 로 고른다. 분해기가 대사 논리에 맞춰 자동 선택하고, UI 컷 카드에서 수동 변경 가능.

| 종류 | 그림 | 언제 | 근거 |
|---|---|---|---|
| `arrow` | 굵은 화살표 1개 | 움직임·경로를 **한 방향**으로 (레퍼런스 47컷 중 14컷 — 최다) | `ANNOTATION_ARROW` L1618 |
| `flow` | **굵은 흐름 띠 1줄** | 힘·하중·물·공기·열·전기가 **출발→경로→도착**하는 여정 전체 | `ANNOTATION_FLOW` L1641 |
| `hud` | 헤어라인 윤곽선 + 치수선 | 치수·수치·계측 (`measure_en` 있으면 거의 항상) | `ANNOTATION_SHAPE` L1672 |
| `glow` | 대상 전체 반투명 점등 | 와이드·항공에서 구조물 **통째** 지목 | `ANNOTATION_GLOW` L1663 |
| `zone` | 닫힌 테두리 + 옅은 면 | 부위가 아니라 **구역·범위** | `ANNOTATION_ZONE` L1634 |
| `reject` | 굵은 X 1개 | 안 되는 방법·실패·금지 (constraint·despair 비트) | `ANNOTATION_REJECT` L1628 |
| `manga` | 집중선 + 충격 기호 | anime 톤 전용 (자동 강제) | `ANNOTATION_MANGA` L1696 |

**강조색 5종** — 자동은 톤별 기본값을 따른다: 시안(3D·다큐 계열, 브랜드색) · 빨강(실사·경고) ·
앰버(열·에너지) · 라임(화학·생물) · 화이트(청사진·빈티지·일러스트). 근거 `ANNO_COLORS` L1624.

**부가 요소** — HUD 계열에만 자동으로 붙는다:
- 치수선 + 눈금: `measure_en` 이 있을 때만 (L1760)
- 지면 원형 측량 그리드: `shot: wide` 일 때만 (L1752) — 클로즈업에 깔면 장식이 된다

## 3. 영상 쪽 동작 (이미지에 구운 것을 어떻게 움직이는가)

**핵심 원칙**: 그림은 2K 이미지에 굽고, 영상은 "이미 있는 것의 변화" 하나만 한다.
가는 선·글자를 영상이 새로 그리면 720p에서 뭉개진다 (실측).

| 모드 | 동작 | 근거 |
|---|---|---|
| `*_draw` | 시작 이미지가 깨끗할 때 → 영상이 1초 내 그려 넣고 고정 | `VIDEO_ANNO_MODES` L1149~ |
| `*_animate` | 시작 이미지에 이미 있을 때 → 밝기 펄스만, 위치 고정 | 〃 |
| `flow_animate` | 띠 위를 **밝은 앞머리 하나**가 출발→도착 1회 통과 후 은은히 유지 | L1240 (2026-08-12) |

**자동 판별**: `_video_anno_kind()` 가 이미지에 주석이 구워졌는지 보고 draw/animate 를 고른다
(L1866). 이미지에 굽고 영상에서 또 그리면 두 벌이 되므로.

## 4. 글자 없는 그래픽 애니메이션 (motion_en 에 덧붙이는 도형 연출)

분해기가 어울리는 컷에 한 구 덧붙인다. **한 영상에 2~3컷까지** (전부 붙이면 계기판이 된다).

| 패턴 | 어울리는 컷 | 근거 |
|---|---|---|
| 호형 게이지가 한계까지 차오름 | 한계·누적·정도 (constraint) | 분해규칙 [4] L2372 |
| 스캔선이 1회 통과, 와이어프레임 잠깐 발광 | 조사·분석·측량 (pivot·solution) | L2374 |
| 측량 그리드가 지면에 칸칸이 펼쳐짐 | 면적·범위 (와이드·항공) | L2376 |
| 막대 2개가 다른 높이로 솟음 | 배수·비교 ("3배", "절반") | L2378 |

## 5. 홀로그램 재구성 — 카메라로 못 찍는 것 (4가지 조건)

실사 현장 위에 시안 와이어프레임을 겹친다. **한 영상에 최대 1~2컷, 연속 금지.**
근거: 분해규칙 [3-1] L2159~2209.

| 조건 | 대사 신호 | beat |
|---|---|---|
| ① 과거 재구성 (사라진 구조) | "원래는", "당시에는", "지금은 사라진" | context·solution |
| ② 투시 재구성 (숨은 내부·지하) | "속에는", "벽 뒤에", "기초는", "땅속에" | constraint·solution |
| ③ 비교·대안 (기각되는 뻔한 답) | "그냥 ~하면 되지 않냐", "~했다면" | constraint·pivot |
| ④ 스케일 비교 | "아파트 ~층 높이", "축구장 ~개" | hook·context |

**철칙**: 배경·실물은 끝까지 100% 실사. 홀로그램이 화면의 주인이 되면 실패 (그 순간 다큐가
아니라 SF가 된다, L2203).

## 8. 컷 잇기 (체인)

- 시작 프레임 = 이 컷 이미지, **도착 프레임 = 다음 컷 이미지** (API `lastFrame`)
- 2026-08-12 추가: 도착 절이 붙어 **크로스페이드·모핑이 아니라 실제 동작으로 도착**하게 강제
  (`VIDEO_LAST_FRAME_ARRIVE` L1360)
- 예외 탈출구: 컷별 `from_prev` 토글 → 앞 클립의 실제 끝 프레임에서 출발 (화질 한 단계 손해)
- **한 영상에 묶음 최대 2개, 묶음당 최대 3컷** — 장면 전환이 사라지면 몰입이 깨진다
