# 지침과 코드 — 어디를 고칠 것인가

"리빌을 좀 더 쓰게 하고 싶다" 같은 요구가 왔을 때, **지침을 고칠 일인지 코드를 고칠 일인지**
가르는 기준. 잘못 고르면 앱을 다시 빌드해놓고 아무것도 안 바뀐다.

---

## 한 줄 기준

> **판단은 지침, 조립은 코드.**
>
> "이 컷에 무엇을 쓸까"는 지침이 정한다. "그 값이 어떤 문장이 되어 나가는가"는 코드가 정한다.

---

## 헷갈리기 쉬운 셋

### 1. 리빌 — 코드는 개수를 세지 않는다

`REVEAL_LINES` 는 **문장만** 갖고 있다. "한 영상에 2~3컷까지" 같은 제한은 **코드에 없다.**
전부 지침 텍스트다. 그래서:

- 리빌을 더 쓰게 하고 싶다 → **지침**
- 리빌 종류를 새로 만들고 싶다 → **코드** (`REVEAL_LINES` 에 추가) **+ 지침** (enum 에 추가)

**둘 다 필요한 경우가 많다.** `stack_split`·`xray` 를 넣을 때 코드에 문장을 넣고 지침의
`reveal` enum 에도 넣었다. 한쪽만 하면: 코드만 → LLM 이 그 값을 모름 / 지침만 → 앱이 무시함.

> 반면 **홀로그램은 코드가 센다** (`holo` 집계 → 3컷 넘으면 경고). 이건 코드 쪽이다.

### 2. 카메라 — 지침은 관여하지 않는다

컷 JSON 에 `camera` 필드가 있긴 하지만, **분해기가 채우도록 지침이 시키지 않는다.**
`_auto_camera` 가 `beat`/`shot`/`type` 을 보고 정하고, 사용자가 UI 에서 고르면 그게 우선한다.
그 위에 강조 강등(`CAMERA_LOUD`)이 얹힌다.

**카메라 프리셋을 추가하는 건 순수 코드 작업이다.** 지침은 손댈 필요가 없다.
UI 도 손댈 필요가 없다 — 프론트가 백엔드 `CAMERA_GROUPS` 를 읽어 그린다.

### 3. 톤 — 양쪽 다

새 톤을 하나 넣으려면:

**코드**
- `STYLE_DEFAULTS[id]` — 영어 톤 문장 (필수)
- `STYLE_LABELS[id]` — 한글 이름 (필수. 여기 없으면 UI 에 안 뜬다)
- `STYLE_GROUPS` — 어느 묶음에 넣을지 (필수)
- `NEG_BY_STYLE` · `ANNO_COLOR_BY_STYLE` — 필요하면
- `SOURCE_STYLES` — 자료 화면 계열이면 (카메라가 묶인다)
- 얼굴 정책 분기 — 인물 톤이면 (`FACE_GAME`/`FACE_MANNEQUIN`/`FACE_ANIME`)
- 영상 룩 잠금 분기 — 인물 톤이면 (`VIDEO_*_LOOK`)
- `ui/tones/{id}.jpg` — 샘플 이미지 (없으면 팔레트에 빈 카드)

**지침**
- `style` enum 에 추가
- `[1]` 톤 선택 규칙에 언제 쓸지 설명

정합성은 `python docs/_현황_뽑기.py` 가 검사해준다 — 빠진 게 있으면 표에 `**없음**` 이 뜬다.

## 지침을 고쳤을 때 반드시 할 일

```
① main.py 의 SCENE_SPLIT_PROMPT 를 고친다
② 앱을 재빌드한다                          ← 앱 내장 분해(Gemini/Opus)에 반영
③ [📋 지침 복사] 를 누른다
④ claude.ai 프로젝트 지식에서 이전 지침을 지운다   ← ★ 빠뜨리기 쉽다
⑤ 새 것을 붙여넣는다
```

**④를 빼먹으면 두 벌이 공존한다.** 지침 첫 줄의 8자리 번호로 대조하라:

```
<!-- 지침 버전 7b6fd7c1 — 앱의 [📋 지침 복사] 로 다시 뽑아 교체하세요 -->
```

현재 번호는 `docs/_현황.md` 맨 위에 있다. **이 번호를 손으로 계산하지 마라** — 앱이
`sha1(본문)[:8]` 로 찍는 값이라 다른 방식으로 계산하면 안 맞는다.

## 코드만 고치면 되는 것 (지침 무관)

- 카메라 프리셋 추가·수정
- 네거티브 문구
- 프롬프트 조립 순서
- 모델·해상도·초·단가
- UI 컨트롤 (판수·잠금 스위치 등)
- 보관·재생성 규칙
- 강조 강등 규칙

## 지침만 고치면 되는 것 (코드 무관)

- 컷 수 계산식의 해석
- beat 배정 요령
- 어느 톤을 언제 쓸지
- 리빌 예산 (형식별 몇 컷까지)
- `subject_en` 에 쓰면 안 되는 어휘
- 캐논 문구 작성법
- 검수 항목

## 어느 쪽인지 헷갈릴 때

**"이 값이 JSON 필드에 담기는가?"** 를 물어라.
- 담긴다 → 값을 **고르는** 규칙은 지침, 값을 **쓰는** 방식은 코드
- 안 담긴다 → 코드
