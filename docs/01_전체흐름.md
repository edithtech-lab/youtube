# 전체 흐름 — 어느 단계에서 무엇이 결정되나

```
① 대본            사람 (또는 claude.ai 대화)
   ↓
② 컷 분해 JSON    claude.ai  ← 앱 밖에서 돈다 ★
   ↓
③ 이미지 프롬프트  앱이 조립 (약 3,500자 영어)
   ↓
④ 2K 이미지       Seedream / Gemini
   ↓
⑤ 영상 (I2V)      Seedance / Veo   720p
   ↓
⑥ 편집            CapCut (사람)
```

**②만 앱 밖에서 돈다.** 이게 이 프로젝트를 이해하는 열쇠다.

---

## ② 컷 분해 — 유일하게 앱 밖

사용자가 claude.ai 대화에서 "컷 분해해줘" 라고 하면, 프로젝트 지식에 올려둔 지침이 작동해
JSON 하나를 뱉는다. 그걸 앱의 `[① JSON 으로 넣기]` 에 붙여넣는다.

> **그래서 지침을 고쳐도 앱 빌드로는 반영되지 않는다.**
> `[📋 지침 복사]` → claude.ai 프로젝트 지식에서 **이전 것을 지우고** 새로 올려야 한다.
> 지침 첫 줄에 8자리 번호가 박혀 있다. 현재 번호는 `docs/_현황.md` 에 있다.

앱 안에서도 분해할 수 있다 (Gemini/Opus API). 같은 원문 지침을 쓴다 — **두 벌로 관리하면
반드시 한쪽만 고쳐지고 그때부터 결과가 갈리기 때문**이다 (`split_guide()` 주석).

### LLM 이 채우는 것은 짧은 값뿐이다

컷 하나가 24개 필드다. 전부 짧다.

```json
{ "no": 3, "style": "docu3d", "shot": "wide", "beat": "constraint",
  "subject_en": "…", "focus_en": "…", "motion_en": "…",
  "anno_kind": "measure", "from_en": "…", "to_en": "…", "measure_en": "70t",
  "reveal": "", "chain": false, "scene_ko": "…", … }
```

**완성된 영어 프롬프트를 쓰게 하지 않는다.** 앱이 이 값들로 조립한다.
LLM 이 문장을 통째로 쓰면 톤이 컷마다 흩어진다.

필드별 설명은 `docs/컷JSON_필드_한글설명.md`.

## 앱이 JSON 을 받은 뒤 하는 일 — `_finish_split`

붙여넣은 JSON 을 그대로 쓰지 않는다. 여러 가지를 검증하고 다듬는다.

| 하는 일 | 왜 |
|---|---|
| 톤 id 정규화 (`norm_style`) | 목록에 없는 값을 지어내면 조용히 `snap` 이 된다 → `STYLE_MIGRATE` 로 구버전 치환 |
| 체인 검증 | 1번 컷은 이을 수 없다. `place_en`·피사체가 바뀌면 끊는다 (LLM 이 "다 이어라"로 폭주함) |
| 글자 수 상한 적용 | 넘치면 자른다 |
| **잘림 리포트** | 자르거나 바꾼 곳을 `trunc` 로 프론트에 넘겨 팝업으로 보여준다 ★ |
| 강조 개수 집계 | 상한이 걸려 있으면 초과분을 끈다 (기본은 무제한) |
| 홀로그램 컷 집계 | 3컷 넘으면 경고 |
| `chars` 채우기 | `anime` 톤만 |

**잘림 리포트가 있는 이유**: 예전엔 조용히 잘렸다. 사용자가 공들여 쓴 값이 사라져도
알 수가 없었다. 지금은 몇 곳이 어떻게 바뀌었는지 팝업으로 보여준다.

## ③④ 이미지 — `docs/02_이미지생성탭.md`

24필드 → 약 3,500자 프롬프트. **순서 자체가 설계다.**

핵심만:
- 톤 직후에 `SUBJECT_LOCK` 을 못박는다 (톤이 피사체를 덮어쓰는 사고 방지)
- 강조는 두 겹 게이트를 통과해야 나온다 — 필드가 비면 **조용히 사라진다**
- 얼굴 정책은 네거티브를 **교체**한다 (빼는 게 아니라)
- 참조 이미지 지시는 **셋 중 하나만** (지시가 서로 정반대)

---

## ⑤ 영상 — `docs/03_영상화_두갈래.md`

**경로가 둘이다.** 컷 영상화와 자료 소스 탭. `_gen_seedance`/`_gen_veo` 에서만 만난다.

핵심만:
- I2V 는 장면·스타일을 **다시 쓰지 않는다** → `subject_en` 이 영상 프롬프트에 안 들어간다
- 자유 문장으로 나가는 건 `motion_en` 하나뿐
- 강조가 붙은 컷은 카메라가 **강등**되고 템포도 `calm` 로 묶인다
- 엔진마다 쓸 수 있는 초가 다르다

### 클립 길이는 대사가 정한다

```python
VID_ALLOWED = (4, 6, 8)
```
1순위는 방금 만든 음성의 **단어 타임스탬프**(실측), 2순위는 글자 수 ÷ 8.7자/초 추정.
**모자라지 않게 올림**한다 — 짧으면 대사가 잘리지만, 길면 캡컷에서 자르면 그만이다.

## 저장 위치

```
{출력폴더}/
  {편 제목}/                    ← project_dir()
    이미지/                     ← 컷 이미지·영상. NN_ 접두로 컷 번호
      v1/  v2/                  ← 재생성 시 이전 판 보관 (_archive_prev)
    _톤테스트/                  ← 톤 비교용 (판수 1 고정)
  자료이미지/
    YYYYMMDD/                   ← 날짜별 ★ (source_outdir)
      v1/  v2/                  ← _archive_one
```

**자료 이미지만 날짜별인 이유**: 본편에 딸린 게 아니라 여러 편에 두루 쓰는 재료다.
편별로 흩어 놓으면 다시 못 찾는다.

## 판수 — 세 탭 모두

같은 것을 1~5판 미리 뽑아두고 나중에 고른다. **비용이 판수만큼 곱해진다** (UI 표시도 곱함).
이미지·컷 영상·자료 소스 영상 셋 다 있다.

---

## 프롬프트 3단계 원칙 — 전 탭 공통

1. 아무것도 안 쓰면 → 톤에 맞는 초안이 자동으로 붙는다
2. 쓰면 → **그게 그대로 나간다**
3. 고정 규칙도 초안에 들어 있으므로, 지우면 **지워진 채로 간다**

**보이는 것이 나가는 것.** 화면에 안 보이는 규칙을 몰래 덧붙이지 않는다.
