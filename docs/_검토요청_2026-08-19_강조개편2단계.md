# 외부 검토 요청 — 강조 개편 2단계 (2026-08-19)

> 이 문서는 외부 AI(GPT Codex 등)/동료 검토용으로 배경부터 자급자족하게 썼다.
> 결정권자는 사용자이며, 여기 적힌 것은 **아직 반영 전인 제안**이다.

## 이 프로젝트가 뭔가

한국어 정보성 다큐 톤 유튜브 쇼츠/롱폼 제작 파이프라인. `main.py` 한 파일 백엔드(~8,600줄),
`ui/index.html` 한 파일 프론트, PySide6 QWebChannel. 흐름:
대본 → 컷 분해 JSON(claude.ai, 앱 밖) → 이미지 프롬프트 조립(앱) → 2K 이미지(Seedream)
→ I2V 영상(Seedance/Veo) → 캡컷 편집.

핵심 설계 원칙: **LLM은 짧은 부품 값만 채우고, 프롬프트 조립 문법은 앱이 소유한다.**
자세한 구조는 `CLAUDE.md`, `docs/01~06`, 실측 기록은 `docs/05_실측기록.md`.

제약 하나가 모든 판단을 지배한다: **우리는 렌더러가 아니다.** 그래픽은 생성 모델이
문구를 보고 그린다. 픽셀·프레임 단위 지시(선 굵기 px, 등장 8~14프레임)는 실행 불가.
문구로 지시 가능한 것: 재질(매트/발광), 색, 형태 규칙, 대략적 타이밍("첫 1초 안에").

## 오늘까지 이미 반영된 것 (검토 대상 아님, 맥락)

레퍼런스 쇼츠 4편을 10fps 전 프레임 기계 측정 + 96프레임 시각 판독으로 분석
(`docs/_아카이브/2026-08-19_레퍼런스4편_분석.md`). 그 결과로:

- 강조 도구 26종 체계 (`ANNO_KINDS`) — **ring 신설** (단순 원 콜아웃, 레퍼런스 최다 빈도)
- **재질 이원화**: arrow·reject·route·count 를 유리·발광 → 매트·불투명으로.
  A/B 실측(7장, `_실험/재질AB/`)에서 신판 완승 — 재질 문구를 Seedream 이 충실히 따름 확인
- **의미별 하이브리드 강조색** (`ANNO_COLOR_BY_KIND`): 도형 도구=빨강, 물리 현상=시안,
  도면 톤=흰색, flow 는 물질색 우선. UI 에서 의미별/자동/단색 선택
- 영상 판 파일명 (`NN_장면_vN.mp4` 누적, 파일 불변 — 캡컷 소재 보호)

## 검토 요청 3건

### ① 강조 상한 — 숫자 상한을 질적 규칙으로 대체

현재 이중 구조:
- 앱: `cap_anno_cuts` — 기본 0(제한 없음), 사용자가 UI 에서 숫자 지정 가능. **그대로 둠.**
- 지침(컷 분해 LLM 지시문): "**한 영상에서 3~4컷만 채워라**" — 이게 실질 병목.

개정안 (지침 문구):
- 숫자 삭제 → "대사가 대상을 짚는 컷은 전부 채워도 된다"
- 질적 규칙으로 대체:
  1. 같은 도구 3컷 연속 금지
  2. 대형 도구(reject·versus·scale)는 편당 1~2회
  3. 분위기 컷(훅 풍경·여운)은 강조 없이 비움 — 자연스러운 숨 구간
  4. "뒤에서부터 예약" 유지 (앱 상한이 켜졌을 때 뒤쪽 회수 컷부터 죽는 문제 방어)

근거: 레퍼런스 4편의 강조는 펄스 구조(평시 0~1% → 강조 5~12% → 복귀)로, 프레임 기준
20~40%에 강조가 있음. 채널 운영자 방침은 "강조는 많을수록 좋다(후킹)". 절충이 위 안.

**검토 포인트**: 질적 규칙 4개가 LLM(분해기)이 지키기 충분히 명확한가? 빠진 게 있나?

### ② 조립(CLEAN→INFO) 속도 — 현상 유지

강조가 큰 컷은 조립 전(CLEAN) 이미지에서 시작해 강조 완성(INFO) 이미지에 도착하는
2컷 체제로 영상화한다 (`ASSEMBLE_STAGES`). 템포는 "클립 1/3 지점까지 완료 후 정지".
더 조이면 시댄스가 초반 프레임에서 형태를 뭉갤 위험(과거 전이 발명 실측 계열)이 있고,
빠른 등장이 필요한 팝 계열(ring·reject)은 조립 대신 draw 경로가 이미 있다.
→ **코드 변경 없음**으로 결론. 이견 있으면 근거와 함께.
