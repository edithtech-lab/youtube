# 이미지 생성 탭 — 프롬프트가 조립되는 순서

컷 JSON 24필드가 어떻게 약 3,500자짜리 영어 프롬프트가 되는가. 전부 `_build_prompt()`
(`main.py`) 안에서 벌어진다. **LLM 은 짧은 값만 채우고, 아래 조립은 전부 앱이 한다.**

```python
def _build_prompt(self, cfg, cut, refs, anno=""):
    ...
    return "\n\n".join(p for p in parts if p)
```

`parts` 리스트에 순서대로 담기고 빈 것은 빠진다. **순서 자체가 설계다** — 몇 개는 자리를
옮기면 망가진다.

---

## 조립 순서

| # | 조각 | 출처 | 조건 |
|---|---|---|---|
| 1 | `SUBJECT: …` | `cut["subject_en"]` (없으면 `scene_ko`) | 항상 |
| 2 | `Setting: …` | `cut["place_en"]` | 있을 때 |
| 3 | `Atmosphere: …` | `cut["weather_en"]` | 있을 때 |
| 4 | `Shot: …` | `SHOT_LINES[shot]` | 항상 (없으면 `close`) |
| 5 | 리빌 | `REVEAL_LINES[cut_reveal(cut)]` | 리빌이 있을 때 |
| 6 | 근거 수준 | `EVIDENCE_LINES[evidence]` | 문화유산 복원 컷만 |
| 7 | **톤** | `STYLE_DEFAULTS[style]` 또는 사용자 오버라이드 | 항상 |
| 8 | 밝기 | `MOOD_LINES[mood]` | 있을 때 |
| 9 | **`SUBJECT_LOCK`** | 고정 문구 | 항상 ★ |
| 10 | 강조 블록 | `annotation_block(anno, cut, color)` | 강조가 켜졌고 실제로 문구가 나올 때 |
| 11 | **네거티브** | `base_neg` + `NEG_BY_STYLE[style]` | 항상 ★ |
| 12 | 참조 이미지 지시 | 셋 중 **하나만** | 참조 이미지가 붙었을 때 |

### ★ 9번 `SUBJECT_LOCK` — 톤 바로 뒤여야 한다

```
The style above controls only how the image looks — lighting, materials, grade …
```

톤 프리셋이 피사체를 덮어쓰는 사고를 막는다. **2026-08-04 실측: `arch3d` 톤이 모든 컷을
댐으로 만들었다.** 톤 문구에 "거대 구조물" 같은 말이 들어 있으면 모델이 그걸 피사체로
읽어버린다. 그래서 톤 **직후**에 "위의 스타일은 생김새만 지배한다"를 못박는다.

### 8번 밝기 — 자리가 정해져 있다

> 톤 바로 뒤에 얹는다. **앞에 두면 톤 문구가 덮어쓰고, 네거티브 뒤에 두면 묻힌다.**

## 강조(annotation) — 두 겹의 게이트

강조는 두 번 걸러진다. 이걸 헷갈리면 "왜 강조가 안 나오지?"에서 막힌다.

```
① anno_for_cut(mode, cut, "full")   ← 이 컷에 강조를 붙일까? (컷 단위 판단)
② annotation_block(anno, cut, color) ← 붙인다면 어떤 문구로? (빈 문자열 반환 가능)
```

**②가 빈 문자열을 돌려주면 강조는 조용히 사라진다.** 필요한 필드가 비어 있으면 그렇게 된다.
`versus` 는 `compare_en`, 화살표·흐름은 `from_en`/`to_en` 이 필요하다.
2026-08-14 에 프론트가 이 4필드를 페이로드에 안 담아서 강조가 **오류 없이** 죽었다.

강조가 실제로 붙었을 때만 네거티브를 완화한다:

```python
if blk:
    base_neg = NEGATIVE_CORE_ANNO_FULL if '"' in blk else NEGATIVE_CORE_ANNO_SHAPE
else:
    base_neg = NEGATIVE_CORE
```

**빈 문구인데 완화하면** "마크를 원한다"는 지시만 남아 맥락 없는 화살표가 흩뿌려진다
(2026-08-06 검증). `'"' in blk` 로 글자가 든 강조인지 도형만인지 가른다.

플랫 톤 + 강조는 따로 처리한다 — 발광 금지와 발광 요구가 부딪히므로 `NEGATIVE_FLAT` →
`NEGATIVE_FLAT_ANNO` 로 갈아끼운다. **강조가 실제로 붙은 컷에서만.**

## 얼굴 정책 — 네거티브를 갈아끼운다

기본은 `FACE_HIDE`(익명 실루엣 강제)다. 인물이 주인공인 톤에서는 이걸 풀어야 하는데,
**그냥 빼는 게 아니라 각 톤의 복제 금지 잠금으로 교체**한다.

```python
if style in ("game", "story3d", "toy3d"):   neg = neg.replace(FACE_HIDE, FACE_GAME)
elif style in ("greycast", "whitecast"):    neg = neg.replace(FACE_HIDE, FACE_MANNEQUIN)
elif style == "anime":                      neg = neg.replace(FACE_HIDE, FACE_ANIME)
```

`FACE_MANNEQUIN` 은 **얼굴이 생기는 것 자체를 막는다** — 회색/흰 마네킹 톤은 얼굴 없음이
정체성이다. 영상 쪽에도 대칭 잠금(`VIDEO_CAST_LOOK`)이 있고, 2026-08-15 실측에서
4초 오빗 내내 얼굴이 안 생기는 것을 확인했다.

## 참조 이미지 — 셋 중 하나만 붙는다

**지시가 서로 정반대라서 둘 이상 붙이면 모순**이 된다.

```python
first = os.path.basename(refs[0])
if style == "anime" and sheet and first == basename(sheet):  CHAR_SHEET_LINE  # 이 인물 그대로
elif subj and first == basename(subj):                       SUBJECT_SHEET_LINE # 이 사물 그대로
else:                                                        STYLE_REF_LINE     # 피사체 복사 금지
```

| 칸 | 지시 | 쓸 때 |
|---|---|---|
| 👥 **캐릭터 시트** | 이 인물을 그대로. 시트의 흰 배경·나열·라벨은 무시하고 장면에 넣어라 | `anime` 톤 전용 |
| 🏛 **피사체 시트** | 이 **물건**을 그대로. 형태·비율·재질·색·마모까지 | 그 편의 주인공 건물·기계·유물 **한 장** |
| 🖼 **톤 레퍼런스** | 룩(빛·색·질감·사실성)만 맞춰라. **피사체·구도는 복사하지 마라** | 톤이 컷마다 흔들리는 편 |

**셋 다 전역 설정이다.** 한 번 걸면 지울 때까지 모든 컷·모든 편에 붙는다.
장면 사진(인물·배경이 같이 든 컷)을 피사체 시트로 걸면 **엉뚱한 컷에도 그 장면이 재현된다.**
`config.json` 의 `char_sheet` / `subject_sheet` / `img_style_refs` 에 들어간다.

## 톤 오버라이드

```python
def _style_block(self, cfg, style):
    ov = cfg.get("img_style_override") or {}
    return (ov.get(style) or STYLE_DEFAULTS[style]).strip()
```

사용자가 팔레트에서 톤 문구를 고쳐 쓰면 `img_style_override[톤]` 에 저장되고 기본값 대신
나간다. **전역 톤 지정은 정상 작동한다** — 5배치 100% 균일함을 확인했다 (`_프롬프트.json`).
톤을 지정했는데 룩이 섞이면 원인은 대개 **`subject_en` 에 매체 어휘가 들어간 것**이다
(`cinematic`, `black-and-white`, `drone shot` …). 지침 `[1]-8` 이 이걸 금지한다.

## 판수 (N판 미리 뽑기)

```python
passes = 1 if is_test else max(1, min(5, int(_num(p.get("passes"), 1))))
for pi in range(passes):
    if not self.img_running: break
```

같은 컷을 여러 판 돌려두고 나중에 고른다. **비용이 판수만큼 곱해진다** — UI 의 비용 표시도
곱해서 보여준다. 톤 테스트(`is_test`)는 1판 고정이다.
