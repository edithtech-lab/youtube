# 강조 도구 총람 ⚙자동생성 — 고치지 말고 `python docs/_강조도구_뽑기.py` 로 다시 뽑을 것

생성 2026-08-19 · 도구 25종 (main.py `ANNO_KINDS` 실측) · 별칭 {'hud': 'measure'}

## 한 컷의 강조가 지나가는 길

```
컷 JSON(anno_kind·focus_en…)  →  이미지: ANNOTATION_* 문구로 2K에 굽는다
                              →  영상:   VIDEO_ANNO_MODES[kind_animate] 가 '잠금+빛 1회'로 지킨다
                              →  조립(옵션): CLEAN→INFO 사이를 ASSEMBLE_STAGES[kind] 순서로 조립
```

- **그래픽은 전부 2K 이미지에 굽는다. 영상은 절대 새로 그리지 않는다** (720p 재작도가 대표 실패).
- 영상 판 공통 문법: 위치·크기·형태·길이 잠금 + 움직이는 것은 '그 안을 지나가는 빛 1회'뿐,
  끝나면 정착(steady glow). 소실(fade out) 전면 금지.
- `focus_en` 이 비면 강조는 통째로 안 들어간다 (이미지·영상 공통).

(장면 자체를 바꾸는 도구라 조립 불가 → 구워서 유지로 폴백).

## 색은 이렇게 정해진다

1. flow 컷 + `flow_of` 지정 → 내용색 강제: cold_air, warm_air, heat, water, force, electricity, smoke, blood
2. 설정의 강조색이 특정 색이면 → 전부 그 색
3. '자동'이면 → 톤별 표(`ANNO_COLOR_BY_STYLE`)

## 글자 규칙 (화면에 실리는 텍스트)

- `measure_en` 수치 12자 — 라틴/숫자만 남는다(한글 삭제: "46년"→"46" — 지침이 46Y 로 쓰게 함)
- `anno_label` 영문 라벨 16자·2단어 — 강조색 박스 태그 + 리더선으로 굽는다. 편당 2~3컷만
- 한글은 절대 굽지 않는다 (실측: "등대 높이"→"롱대 늪이"). 한글 설명은 편집 자막으로
- **영상에는 수치·글자를 절대 새로 새기지 않는다** (실측: "20km"→"2?:00")

## 조립 강조 (CLEAN→INFO)

- 켜면 강조 컷마다 CLEAN(그래픽 없음)을 먼저 뽑고 INFO 를 편집 생성 — 비용 2배, CLEAN 은 `이미지/조립전/`
- 영상은 CLEAN 에서 시작해 INFO 를 lastFrame 으로 고정 — 그래픽이 조립되며 끝상태 소실 불가
- 조립 제외: ['measure', 'scale', 'versus'] — 장면 변경형이라 모델이 모핑으로 때움 (1편 실측)
- Veo 는 first+last 보간이 **8초 전용** — 다른 초는 조립을 접고 경고만 낸다
- arrow 조립은 '완성 화살표가 날아와 착지' — 몸통 성장 금지 (2026-08-18 결정)

## 어디를 고치나

| 고치고 싶은 것 | 위치 (main.py 상수) |
|---|---|
| 이미지에 그려지는 모양 | `ANNOTATION_<도구대문자>` 문구 |
| 어떤 도구를 쓸지 판정·필수 필드 | `annotation_block()` 디스패치 |
| 영상에서의 움직임 | `VIDEO_ANNO_MODES["<도구>_animate"]` |
| 조립 순서 | `ASSEMBLE_STAGES["<도구>"]` / 제외는 `ASSEMBLE_SKIP` |
| 도구 등록 자체 | `ANNO_KINDS` (+지침 enum — [📋 지침 복사] 로 claude.ai 교체 필요) |
| 색 | `FLOW_COLORS` · `ANNO_COLOR_BY_STYLE` |

도구를 새로 만들 때 채울 곳 6군데: 상수 → 디스패치 → `<도구>_animate` → 조립 스테이지 →
`ANNO_KINDS` → 지침(enum+설명, 해시 갱신). 하나라도 빼먹으면 이 문서를 다시 뽑았을 때 표에 구멍이 보인다.
