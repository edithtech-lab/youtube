ℹ 계정 칸 자세한 설명 (AK/SK · ep)

· ep를 적어두면 그 접근 지점을 고를 때 해당 계정 키가 자동으로 1순위가 됩니다 (안 적으면 키를 하나씩 시도하느라 호출이 낭비됩니다).
잔량은 계정 줄의 AK/SK로 계정마다 따로 조회합니다(ListModelChargeItems) — 위 계정 칸을 채우면 [잔여 확인]에서 콘솔과 같은 실측값이 나옵니다.

⚠ AK/SK는 ark- 키보다 권한이 셉니다(계정 리소스 조작 가능). config.json에 평문으로 저장됩니다.
