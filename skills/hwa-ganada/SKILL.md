# 화 가나다

화 가나다 채널 작업에서 [프로젝트 지침 V3.3 통합본](references/project-guidelines-v3.3.md)을 완전히 읽고 최우선 기준으로 적용한다.

- 대본 모드와 대본 수정·검수에서는 [Gold Standard Reference #1](references/gold-standard-reference-01.md)도 읽고 문체·리듬·정보 배치·TTS 호흡의 품질 기준으로 사용한다. 고유 문장과 소재는 복제하지 않는다.
- 컷분해 모드에서는 [컷분해지침](references/cut-guidelines.md)도 완전히 읽는다. 충돌 시 V3.3의 화 가나다 오버라이드가 우선한다.

## 모드

사용자 요청에서 다음 하나만 선택한다.

- 소재 모드: 주제·소재 추천 요청
- 대본 모드: 지정 소재의 대본 요청
- 수정·검수 모드: 기존 화 가나다 대본의 평가·수정·압축·훅 개선 요청
- 컷분해 모드: 완성 대본의 컷분해 요청

묻지 않은 모드의 결과물을 함께 만들지 않는다.

## 판별 규칙

- 소재만 요청하면 소재 모드다. 대본을 미리 쓰지 않는다.
- 실존 인물·사건을 지정하면서 대본을 요청하면 대본 모드다. 소재 추천을 다시 하지 않는다.
- 기존 원고의 평가·수정·압축을 요청하면 수정·검수 모드다.
- 컷분해라는 말을 명시한 경우에만 컷분해 모드다.
- 요청이 정말 애매하면 한 번만 확인하고 두 모드를 동시에 출력하지 않는다.

## 필수 운영

- 소재와 대본은 기억으로 확정하지 말고 웹에서 검증한다.
- 공식 1차 자료를 우선하고, 지침의 숫자·출처 하드라인을 지킨다.
- 친일·부역·배신·권력 남용 소재에서는 분노와 통쾌함을 허용하되 사실로 감정을 만든다.
- 비슷한 후보끼리는 실제 권선징악·자업자득 Payoff가 선명한 소재를 우선한다.
- 실제 기록에 없는 응징이나 인과를 만들지 않는다.
- 최종 출력 전 지침의 자체 검수와 개정·통합 검수를 적용한다.
