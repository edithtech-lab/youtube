# 18점

18점 채널 요청에서 다음 모드 중 하나만 선택한다. 묻지 않은 모드의 결과물을 함께 만들지 않는다.

## 모드 라우팅

- 소재 모드: 주제·소재 추천, 할 만한 물건 요청. [마스터 V7.8](references/master-v7.8.md)과 [레퍼런스 대본 DB](references/reference-script-db.md)를 완전히 읽는다. 기본 후보 5개만 제안하고 사용자가 고르기 전 대본을 쓰지 않는다.
- 대본 모드: 하나의 대상·주제·각도로 대본 요청. 마스터 V7.8과 레퍼런스 DB를 완전히 읽고 지정 출력 포맷만 제공한다. 별도 소재 목록을 다시 추천하지 않는다.
- 수정·검수 모드: 기존 18점 대본의 평가·압축·훅 개선. 마스터 V7.8과 레퍼런스 DB를 읽고 검증된 장점과 사실을 보존하며 요청 범위만 수정한다.
- 컷분해 모드: 사용자가 컷분해를 명시한 경우에만 마스터 V7.8과 [컷분해지침](references/cut-guidelines.md)을 완전히 읽는다. 대본을 새로 쓰거나 소재를 추천하지 않는다.

## 판별 규칙

- 소재만 요청하면 소재 모드다. 대본을 미리 쓰지 않는다.
- 물건·브랜드를 지정하면서 대본을 요청하면 대본 모드다. 소재 추천을 다시 하지 않는다.
- 기존 원고의 평가·수정·압축을 요청하면 수정·검수 모드다.
- 컷분해라는 말을 명시한 경우에만 컷분해 모드다.
- 요청이 정말 애매하면 한 번만 확인하고 두 모드를 동시에 출력하지 않는다.

## 절대 경계

- 18점은 반말 구어체다. 시그니처 한 줄을 제외하고 존댓말 설명조를 사용하지 않는다.
- 랜드마커의 존댓말 건축 다큐와 화 가나다의 사건 발견형 문체를 섞지 않는다.
- 소재·대본 모드에서는 웹으로 핵심 주장과 URL을 검증하고 팩트 블록을 생략하지 않는다.
- 레퍼런스 DB에서는 구조·감정선·호기심 루프만 참고하고 문장·펀치라인·고유 표현을 복제하지 않는다.
- 출력 전 마스터의 훅, 시그니처, 570자 상한, 어미 비율, 비대칭 루프, 자막, 소싱 표, 팩트 블록 검수를 실제로 수행한다.
