# 자동생성 문서 갱신

목록·개수는 외우지 말고 뽑는다 (절대 규칙 3). 자동생성 문서는 2개:

1. ```
   python docs/_현황_뽑기.py        # docs/_현황.md — 톤·카메라·리빌·모델·단가
   python docs/_강조도구_뽑기.py     # docs/06_강조도구.md — 강조 도구 총람
   ```
   둘 다 main.py 를 임포트해 실시간으로 센다. 손으로 고치지 말 것 — 다음 생성 때 덮인다.

2. `docs/06` 출력에 `⚠ INFO 표에 설명이 없는 도구` 경고가 있으면
   `docs/_강조도구_뽑기.py` 의 INFO 표에 그 도구 한 줄을 추가하고 다시 뽑는다.

3. CLAUDE.md 의 "어디를 봐야 하나" 표와 실제 docs/ 목록을 대조한다 —
   문서를 새로 만들었으면 표에 한 줄 추가 (이정표 없는 docs 는 없는 것과 같다).

4. 실험 증거물을 새로 만들었으면 `_실험/<이름>/` 에 넣고
   `docs/05_실측기록.md` 맨 끝 "증거물 위치" 표에 한 줄 추가.
